# Old Photo Restorer

A desktop image restoration application built with Python,
OpenCV, NumPy, SciPy, Pillow, Matplotlib and PySide6.

## Goal

Restore and enhance old or degraded photographs using classical
Digital Image Processing techniques.

## Planned Modes

- Quick Restore
- Photo Repair
- Advanced

## Planned Processing Pipeline

Load
→ Analyze
→ Prepare
→ Restore
→ Finish
→ Compare
→ Export

## Technology

- PySide6
- OpenCV
